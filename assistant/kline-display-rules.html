2. 个股详情页面

2.1 入口位置

用户在“智能选股-选股结果”、“自选”、“甄选优股”、“优息股”、“科技主线”、“发现异动”、“范例实盘”、“模拟操盘”、“K线捕手”、“AI异动筛股”、“科技强度”模块点击单只股票卡片(股票名称代码»)，进入个股详情页。

2.2 页面标题

顶部红色标题栏展示：

  • 股票名称
  • 股票代码
  • 返回按钮

股票名称和股票代码居中上下显示。

2.3 返回逻辑

点击左上角返回按钮，关闭个股详情页，回到上一级页面。

3. 页面顶部行情摘要

3.1 展示字段

日K顶部行情摘要区展示以下字段：

  • 当前价
  • 涨跌额
  • 涨跌幅
  • 最高价，简称“高”
  • 最低价，简称“低”
  • 开盘价，简称“开”
  • 市值
  • 换手率，简称“换”
  • 流通市值，简称“流通”
  • 量比
  • 市盈率 TTM
  • 成交额，简称“额”

其他周期顶部行情摘要区展示以下字段：

  • 当前价
  • 涨跌额
  • 涨跌幅
  • 最高价，简称“高”
  • 最低价，简称“低”
  • 开盘价，简称“开”
  • 换手率，简称“换”
  • 成交量，简称“量”
  • 成交额，简称“额”

3.2 字号和样式

当前价字号较大，但不应过粗。

右侧灰色字段标签字号保持一致；TTM 要比“市盈”文字更小。

3.3 颜色规则

当前价、涨跌额、涨跌幅：

  • 相对前收盘价上涨：红色
  • 相对前收盘价下跌：绿色
  • 持平：普通深色

高、低、开：

分别与前收盘价比较

  • 高于前收盘价：红色
  • 低于前收盘价：绿色
  • 等于前收盘价：普通深色

量比：

  • 量比 > 1：红色，表示放量
  • 量比 = 1：普通深色，表示无明显放量
  • 量比 < 1：绿色，表示缩量

换手率：

  • 始终普通深色，不设置高低档位颜色

市值、流通、市盈 TTM、成交额、成交量：

  • 普通深色

3.4 十字线联动

当用户在 K 线图中移动十字线时，顶部行情摘要、主图、副图数据需要根据十字线指向日期同步变化，十字线离开 K 线区域后，顶部行情摘要、主图、副图数据恢复为当前最新行情。

3.5 不同周期顶部行情摘要数据规则

顶部行情摘要需要跟随当前 K 线周期和十字线选中 K 线同步变化。

默认状态：

  • 未显示十字线时，顶部行情摘要展示当前最新交易日的最新日K数据
  • 切换到周K、月K、季K、年K后，若未显示十字线，顶部行情摘要仍展示当前最新交易日行情，不强制切换为周期汇总行情
  • 显示十字线后，顶部行情摘要展示十字线所指向的当前周期 K 线数据
  • 十字线消失后，顶部行情摘要恢复当前最新交易日行情

不同周期下，十字线选中某根 K 线时，顶部字段取值规则：

  • 当前价：当前周期 K 线的收盘价
  • 涨跌额：当前周期收盘价 - 当前周期前一根同周期 K 线的收盘价
  • 涨跌幅：涨跌额 / 当前周期前一根同周期 K 线收盘价 * 100%
  • 高：当前周期 K 线最高价
  • 低：当前周期 K 线最低价
  • 开：当前周期 K 线开盘价
  • 市值：取值实现见”K线技术实现方案“文档（周K/月K/季K/年K不展示）
  • 换：取值实现见”K线技术实现方案“文档
  • 流通：取值实现见”K线技术实现方案“文档 （周K/月K/季K/年K不展示）
  • 量比：取值实现见”K线技术实现方案“文档（周K/月K/季K/年K不展示）
  • 市盈率 TTM：取值实现见”K线技术实现方案“文档（周K/月K/季K/年K不展示）
  • 额：取值实现见”K线技术实现方案“文档
  • 量：取值实现见”K线技术实现方案“文档

不同周期对应关系：

  • 日K：显示十字线后，顶部摘要展示该交易日的日K行情数据
  • 周K：显示十字线后，顶部摘要展示该周聚合后的周K行情数据
  • 月K：显示十字线后，顶部摘要展示该月聚合后的月K行情数据
  • 季K：显示十字线后，顶部摘要展示该季度聚合后的季K行情数据
  • 年K：显示十字线后，顶部摘要展示该年聚合后的年K行情数据

特殊交易状态处理：

新股上市首日：

  • A 股新股上市首日，涨跌额和涨跌幅不按开盘价计算，而是按发行价计算。
  • 涨跌额：收盘价 - 发行价 (取值实现见”K线技术实现方案“文档)
  • 涨跌幅：涨跌额 / 发行价 * 100% (取值实现见”K线技术实现方案“文档)
  • K 线颜色仍按 收盘价 vs 开盘价 判断，发行价不参与 K 线红绿判断。

上市首个周K/月K/季K/年K：

  • 若当前周K/月K/季K/年K为股票上市后的第一个对应周期，且不存在前一根同周期 K 线，则涨跌额、涨跌幅按发行价作为比较基准。
  • 上市首个周K/月K/季K/年K周期开盘价仍取上市首日所在周期内第一根有效日K的开盘价。
  • 上市首个周K/月K/季K/年K周期收盘价仍取该周期内最后一根有效日K的收盘价。
  • K 线颜色仍按 周期收盘价 vs 周期开盘价 判断，不按发行价判断。

停牌：

  • 停牌日没有有效交易，不生成日K。
  • 停牌日不参与周K/月K/季K/年K的 OHLC、成交量、成交额聚合。
  • 横轴日期跳过停牌日，不强制补空白柱。
  • 若整个周期都处于停牌或无交易状态，则该周期 K 线不展示，顶部行情摘要不进入该周期数据状态。

复牌：

  • 复牌日作为新的有效交易日正常生成 K 线。
  • 日K按复牌日开盘价、最高价、最低价、收盘价生成。
  • 周K/月K/季K/年K中，复牌日参与所在周期聚合。
  • 涨跌额、涨跌幅通常以上一有效交易日收盘价为比较基准。
  • 若复牌伴随除权除息、重组、重新上市等特殊情形，以行情源返回的价口径为准。 (取值实现见”K线技术实现方案“文档)

除权除息：

  • 除权除息日的开高低收、前收价、涨跌额、涨跌幅，以当前复权设置对应的行情源数据为准。
  • 前复权：使用前复权口径下的 OHLC、均线和十字线价格。
  • 后复权：使用后复权口径下的 OHLC、均线和十字线价格。
  • 除权：使用原始不复权 OHLC。

整周期无交易：

  • 若某个周/月/季/年周期内没有任何有效交易日，则该周期不生成 K 线。
  • 顶部行情摘要不展示该周期聚合数据。
  • 副图也不生成对应数据。

数据来源与兜底原则：

  • 对于周期应展示但接口缺失的字段，统一显示 --。

4. K 线主图

4.1 周期类型

K 线周期展示为：

  1. 日K
  2. 周K
  3. 月K
  4. 季K
  5. 年K

不展示分时周期。

4.2 默认周期

默认选中日K。

4.3 主图均线

主图展示以下均线：

  • MA5
  • MA10
  • MA20
  • MA30

均线数值注释颜色必须与图中均线颜色一致。

4.4 K 线颜色显示规则

K 线主图需要按当前周期 K 线的开盘价和收盘价关系显示红绿颜色。

4.4.1 涨跌持平状态判定

单根 K 线状态：

  • 上涨阳线：周期收盘价 > 周期开盘价
  • 下跌阴线：周期收盘价 < 周期开盘价
  • 持平 K 线：周期收盘价 = 周期开盘价

显示标准：

  • 上涨阳线：红色 K 线，实体可为空心或实心（设计根据情况决定），但同一产品内必须统一
  • 下跌阴线：绿色 K 线，实体使用实心
  • 持平 K 线指 周期收盘价 = 周期开盘价，表示该周期实体持平，但不等同于相对前收价涨跌持平
  • 持平 K 线颜色需结合 周期收盘价 vs 前收价 判断：

- 周期收盘价 > 前收价：显示红色

- 周期收盘价 < 前收价：显示绿色

- 周期收盘价 = 前收价：显示普通深色或灰色

  • 持平且 最高价≠最低价：保留上下影线，颜色按上述规则判断
  • 持平且 开盘价 = 最高价 = 最低价 = 收盘价：显示为一字线，颜色按上述规则判断
  • 一字涨停：开盘价 = 最高价 = 最低价 = 收盘价，且 收盘价 > 前收价，显示红色
  • 一字跌停：开盘价 = 最高价 = 最低价 = 收盘价，且 收盘价 < 前收价，显示绿色
  • 最高价和最低价影线颜色与该 K 线实体颜色一致
  • 新股上市首日的 K 线颜色仍按 收盘价 vs 开盘价 判断，不按发行价判断；发行价只用于首日涨跌额、涨跌幅等行情摘要字段的比较基准，特殊处理：

收盘价 = 开盘价，且 收盘价 > 发行价：红色

收盘价 = 开盘价，且 收盘价 < 发行价：绿色

收盘价 = 开盘价，且 收盘价 = 发行价：普通深色或灰色

4.4.2 不同周期时间点说明

周K：

  • 周期开盘价：该自然周内第一根有效日K的开盘价
  • 周期收盘价：该自然周内最后一根有效日K的收盘价
  • 最高价：该自然周内所有有效日K最高价的最大值
  • 最低价：该自然周内所有有效日K最低价的最小值
  • 时间点说明：周K通常在该周最后一个交易日收盘后固定；若当前周未结束，则使用截至最新收盘日的周内数据生成临时周K

月K：

  • 周期开盘价：该自然月内第一根有效日K的开盘价
  • 周期收盘价：该自然月内最后一根有效日K的收盘价
  • 最高价：该自然月内所有有效日K最高价的最大值
  • 最低价：该自然月内所有有效日K最低价的最小值
  • 时间点说明：月K通常在该月最后一个交易日收盘后固定；若当前月未结束，则使用截至最新收盘日的月内数据生成临时月K

季K：

  • 周期开盘价：该自然季度内第一根有效日K的开盘价
  • 周期收盘价：该自然季度内最后一根有效日K的收盘价
  • 最高价：该自然季度内所有有效日K最高价的最大值
  • 最低价：该自然季度内所有有效日K最低价的最小值
  • 时间点说明：季K通常在该季度最后一个交易日收盘后固定；若当前季度未结束，则使用截至最新收盘日的季度内数据生成临时季K

年K：

  • 周期开盘价：该自然年内第一根有效日K的开盘价
  • 周期收盘价：该自然年内最后一根有效日K的收盘价
  • 最高价：该自然年内所有有效日K最高价的最大值
  • 最低价：该自然年内所有有效日K最低价的最小值
  • 时间点说明：年K通常在该年最后一个交易日收盘后固定；若当前年份未结束，则使用截至最新收盘日的年内数据生成临时年K

4.4.3 不同周期 OHLC 聚合规则

  • 开盘价：当前周期内第一根有效日K的开盘价
  • 最高价：当前周期内所有有效日K最高价的最大值
  • 最低价：当前周期内所有有效日K最低价的最小值
  • 收盘价：当前周期内最后一根有效日K的收盘价
  • 成交量：当前周期内所有有效日K成交量之和
  • 成交额：当前周期内所有有效日K成交额之和
  • 若周期内遇到停牌日或无交易日，不参与 OHLC、成交量、成交额聚合
  • 若整个周期无有效交易数据，则该周期 K 线不展示

4.5 价格刻度

价格显示规则：

  • 主图按四等分横向虚线分隔
  • 价格标注显示在对应横线附近
  • 价格文字位于图内，不额外挤占左侧空间

4.6 放大缩小

要有 K 线放大、缩小功能。

展示方式：

  • 缩小按钮 - ：缩小增加K线展示数据；
  • 放大按钮 + ：放大减少K线展示数据；
  • 按钮浮在主图底部

4.7 复权设置

K 线周期右侧展示设置按钮，目前只提供复权设置功能。

点击设置按钮弹出复权设置弹窗，选项包括：

  • 前复权
  • 除权
  • 后复权

默认选中前复权。

5. 副图指标

5.1 指标类型

副图支持以下指标：

  • 成交量
  • 成交额
  • KDJ
  • MACD

5.2 指标选择方式

副图指标通过下拉选择切换。

5.3 成交量/成交额单位设置规则

成交量、成交额以及相关均线参数需要按数值大小自动换算单位，避免展示过长数字。

5.3.1 成交量、成交额展示单位规则：

  • 小于 10,000：直接显示原始数值，可保留 0 到 2 位小数
  • 大于等于 10,000 且小于 100,000,000：换算为“万”
  • 大于等于 100,000,000 且小于 1,000,000,000,000：换算为“亿”
  • 大于等于 1,000,000,000,000：换算为“万亿”

5.3.2 成交量、成交额展示精度规则：

  • 默认保留 2 位小数
  • 若小数末尾为 0，可去掉无意义的 0

5.3.3 均线参数单位

  • 成交量 MA5/MA10、成交额 MA5/MA10 的单位应与当前指标成交量、成交额的展示单位规则和精度规则一致。
  • 指标成交量、成交额当前值和均线值应分别按自身数值大小换算，不强制所有值使用同一单位。

5.3.4 展示一致性

  • 同一行参数中，数字和单位之间不加空格
  • 单位文字使用中文：万、亿、万亿

5.4 成交量指标

成交量副图展示：

  • 红绿成交量柱
  • MA5 均线
  • MA10 均线
  • 参数展示

参数示例：

  • 量:4.91万
  • MA5:35.69万
  • 10:32.16万
  • 换手:10.36%

注意：均线参数颜色必须与图中MA5/MA10线颜色一致。

5.5 成交额指标

成交额副图展示：

  • 红绿成交额柱
  • MA5 均线
  • MA10 均线
  • 参数展示

参数示例：

  • 额:8.67亿
  • MA5:59.01亿
  • 10:45.07亿
  • 换手:10.36%

注意：均线参数颜色必须与图中MA5/MA10线颜色一致。

5.6 KDJ 指标

KDJ 参数展示：

  • (9, 3, 3)
  • K
  • D
  • J

注意：K/D/J 文字颜色必须与图中 K/D/J 线颜色一致。

5.7 MACD 指标

MACD 参数展示：

  • (12, 26, 9)
  • MACD
  • DIFF
  • DEA

注意：MACD、DIFF、DEA 文字颜色必须与图中对应柱线和曲线颜色一致。

6. 十字线

6.1 触发方式

用户在 K 线图区域手指点击时显示十字线，默认显示5秒，5秒内再点击时隐藏。

用户在K 线图区域长按，十字线显示且不松手时可左右拖动十字线。

6.2 标签展示

主图区域显示对应价格标签。

主图底部显示十字线指向日期。

7. K 线下方展示功能

7.1 分类展示

K 线下方展示同级类别：

  • 基本面
  • 基本信息
  • 概念分析
  • 财务评分
  • 主力持仓
  • 主营结构
  • 最新研报
  • AI风险扫描

7.2 默认展示

默认展示“基本面”内容。

8. 数据口径

8.1 K 线更新频率

K 线数据按每日收盘后更新。

8.2 默认数据

页面初始状态展示最新收盘后数据。
